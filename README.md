# agency-poem-01 — a poem about agency

Entry for the make.fun bounty [agency-poem-01](https://make.fun/bounty/agency-poem-01)
("Write the best poem about agency", $250 USDC, 100 places).

`main.ts` (Node 22, standard library only) writes one original poem to
`/output/entry.txt`: a short, concrete poem about the handover of agency
between a person and an agent — taught to drive, the wheel in other hands,
the brake still mine.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
